# Visual Spatial Cueing Task (Emotion and Attention)

A PsychoPy experiment investigating whether angry vs. neutral facial expressions influence attentional shifts in a gaze-cueing task.

## Overview

A face with a directional gaze appears in the centre of the screen, followed by a target on the left or right. Participants respond as quickly as possible to the target's location. The task measures reaction time and accuracy, comparing congruent trials (gaze points to the target) with incongruent trials (gaze points away).

The research question is whether angry faces lead to faster or more accurate responses than neutral faces, and whether this effect depends on cue validity.

## Design

**Independent variables**
- Emotion: angry vs. neutral facial expression
- Cue validity: congruent (valid) vs. incongruent (invalid)

**Dependent variables**
- Reaction time (RT)
- Accuracy

## Trial Timing

Fixation (ITI) → Cue (400 ms) → SOA delay → Target → Reminder if no response within 1 s → Target disappears after a response or 2.8 s after cue onset

- **Stimulus onset asynchrony (SOA):** randomly selected from 0.1, 0.2, 0.3, 0.5 and 0.7 s to reduce predictability.
- **Inter-trial interval (ITI):** randomly selected from 1.0, 1.2, 1.4, 1.6 and 1.8 s to increase temporal uncertainty.

Timing values are counterbalanced across all trial conditions.

## Experiment Structure

1. **Instruct** – initial instructions
2. **Welcome** – introduction to the task
3. **Trial** – practice block
4. **Feedback** – trial-by-trial feedback: "Correct", "Incorrect", "Too Slow" or "No Response"
5. **EndOfPractice** – end-of-practice message
6. **Trial1** – main experimental block with randomised conditions
7. **Finish** – final screen

## Implementation Notes

- Built in PsychoPy Builder (v2024.1.0) with custom Python code components.
- Reaction time is measured with a clock reset at target onset.
- Participants press **A** if the target appears on the left and **L** if it appears on the right.
- Trial conditions are loaded from spreadsheet files, so the design can be changed without editing code.

## Files

## Running the Experiment

1. Install [PsychoPy](https://www.psychopy.org/) (latest stable version recommended).
2. Add the face cue images (see note below).
3. Open `spatialcueingtask.psyexp` and press the green Run button.
4. Data is saved automatically to a `data/` folder, named with the participant ID and a timestamp.

## Note on Stimuli

The face cue images are not included in this repository because they are third-party stimuli. To run the experiment, create a `cueimages/` folder and add your own images named `cue1.png` (angry) and `cue2.png` (neutral).
